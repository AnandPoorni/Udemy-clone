Udemy Clone Project
Project Title: Udemy Clone – Online Learning Platform

Overview:  
This project is a front‑end clone of Udemy, designed to replicate the look and feel of a modern e‑learning platform. It showcases trending courses, a shopping cart system, and responsive layouts using HTML, CSS, and JavaScript. The goal is to demonstrate practical web development skills while building a user‑friendly interface for online education.

Features:

🎓 Trending Courses Section: Displays popular courses with thumbnails, titles, instructors, ratings, and discounted prices.

🛒 Shopping Cart: Interactive cart icon with item count, dropdown preview, total price, and checkout button.

📱 Responsive Design: Grid layout adapts to desktop, tablet, and mobile screens.

✨ Modern UI Effects: Hover animations, shadows, and badges for bestseller courses.

🔍 Scalable Structure: Easy to extend with search filters, dark mode, or wishlist functionality.

Technologies Used:

HTML5 → Semantic structure for course cards and cart.

CSS3 → Grid layout, hover effects, badges, and responsive design.

JavaScript (optional) → Dynamic cart updates, item removal, and localStorage integration.

Learning Outcomes:

Improved understanding of CSS selectors, units, and grid systems.

Hands‑on practice with responsive design and UI/UX principles.

Experience in building a real‑world styled project that mimics a professional platform.
